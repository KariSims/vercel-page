Ce projet n'utilise actuellement aucun composant, image ou police tierce nécessitant une mention d'attribution.

**Historique** : à l'origine (export Figma Make), ce projet incluait des composants [shadcn/ui](https://ui.shadcn.com/) (licence MIT) et des photos [Unsplash](https://unsplash.com/license). Les deux ont été retirés du code lors du nettoyage du scaffold inutilisé (voir `docs/HISTORIQUE.md`, session du 2026-07-27). Depuis le 2026-08-12, le projet contient de nouveau une image : `public/kumpax-logo.png`, le logo propriétaire de KumpaX (fourni directement par l'utilisateur, pas une ressource tierce) — aucune attribution requise.

Les polices utilisées (Merienda, Inter) sont chargées depuis Google Fonts (`src/styles/fonts.css`) ; leur licence (SIL Open Font License) n'exige pas de mention d'attribution.
